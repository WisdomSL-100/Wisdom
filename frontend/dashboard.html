About assessment modes

Bounded simulator flooding is available for every node in all modes. Service-center safe still blocks the separate DoS scenario and high or critical severity.

About baseline checks

When enabled, fresh baseline diagnostics and probes run before the attack. When off, those checks are skipped.

Demo pathApply an OTA package, select its target, run a scan, then review the report.

Attack and protocol-test capabilities

Available tests: Replay test; Spoofing / unauthorized-message test; Tampering / integrity test; Flooding / DoS resilience test; Unauthorized diagnostic / service-access test; Cross-zone segmentation test; Invalid firmware / secure-flashing test; IDS and auditability regression test.

Bounded protocol probes: CAN/CAN-FD ID and signal-range validation, stale sequence and periodicity checks, authentication rejection, malformed SOME/IP and DoIP headers, unsupported UDS DID/RID, malformed UDS length, and an incorrect SecurityAccess key in copied ECU state.

All activity is simulator-only. Timed attack scenarios send bounded CAN/CAN-FD frames, UDS requests, or invalid-firmware probes through the selected simulator socket handlers; socket events show accepted and rejected traffic. Protocol probes exercise simulator validation handlers. No traffic is sent to a physical vehicle network.
